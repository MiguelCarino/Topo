        Change

          Spreadsheet

          Each sheet is a CSV file any spreadsheet opens (UTF-8, accents and all). Copy as TSV puts the same rows on the clipboard, to paste straight into an open sheet.

          Paste rows copied from a spreadsheet, or open a CSV file. Rows are matched to devices by id, MAC, IP or name; a row that matches none adds a device. Nothing changes until you apply it.

          Or paste an ARP table or a DHCP lease list as a router, a switch, a server or a PC prints it, from any vendor: each address seen with its MAC becomes a row.
